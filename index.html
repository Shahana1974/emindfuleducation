INTERACTIVE DEMO CLASS · GRADES 9–10

Build and program an obstacle-avoiding robot

Discover how sensors, microcontrollers and motors work together. Read the lesson notes, then experiment with the complete Robotics Lab Version 5.2.

1 · Observe

Identify the Arduino Uno, HC-SR04, L298N, battery, chassis and motors.

2 · Build

Assemble the robot and practise simulated pin connections.

3 · Code

Use IF–ELSE logic to control movement based on distance.

4 · Test

Run obstacle challenges and explain your results.

Lesson notes: How an obstacle-avoiding robot works

Input: The HC-SR04 ultrasonic sensor sends a sound pulse and measures how long the echo takes to return. Distance (cm) ≈ echo time (µs) × 0.0343 ÷ 2. We divide by 2 because the sound travels to the obstacle and back.

Processing: The Arduino Uno compares the measured distance with a threshold (for example, 20 cm).

Output: The Arduino signals the L298N motor driver, which controls the DC motors. When an obstacle is near, the robot can stop, reverse and turn.

Safety: Motors must not be powered directly from Arduino I/O pins. Verify motor supply voltage, common ground and the manufacturer's pin diagram before building physical hardware.

Classroom questions and answers
  1. Why is a motor driver needed? Motors draw more current than an Arduino output pin can safely supply.
  2. What is the role of the sensor? It measures the distance to nearby objects using ultrasonic echoes.
  3. What does IF distance ≤ 20 cm mean? The obstacle is close enough to trigger the programmed avoidance action.
